# Terminal Coding Agent

This repository implements an **autonomous terminal coding agent** built with TypeScript and Node.js. The agent can inspect a project, make code changes, run commands, and iterate until a task is completed, all driven by a large language model (LLM) via the Groq API.

## Features

- **LLM‑driven automation** – Uses the Groq SDK (model `openai/gpt-oss-120b`) to understand user prompts and decide which actions to take.
- **Tool suite** – The agent can:
  - List files and directories (`list_files`)
  - Read file contents (`read_file`)
  - Create new files (`write_file` – create‑only)
  - Edit existing files (`edit_file`)
  - Execute shell commands (`run_command`)
- **Robust retry logic** – Calls to the LLM are retried up to 5 times with exponential back‑off.
- **Command‑line interface** – Interactive REPL (`src/cli.ts`) that accepts prompts and runs the agent.
- **Safety rules** – The agent follows strict guidelines to avoid unintentionally overwriting files, removing environment variables, or deleting dependencies.

## Setup

1. **Clone the repository** (if you haven't already):
   ```bash
   git clone https://github.com/akshatchitransh/Terminal_coding_agent.git
   cd Terminal_coding_agent
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Create a `.env` file** with your Groq API key:
   ```dotenv
   GROQ_API_KEY=your_groq_api_key_here
   ```

4. **Build the TypeScript source**:
   ```bash
   npm run build
   ```

5. **Run the agent** (interactive mode):
   ```bash
   npm start
   ```
   You will see a prompt (`>`) where you can type natural‑language instructions, e.g., `Create a README file describing this project`.

## Usage as a CLI Tool

The package defines a binary `myagent` that points to the compiled CLI:

```bash
npm link   # makes `myagent` available globally
myagent -p "Create a new utility function that formats dates"
```

## Contributing

Feel free to open issues or submit pull requests. When contributing:
- Follow the existing coding style (ESM modules, async/await).
- Ensure any new files are added via the `write_file` tool (or manually if you are a contributor).
- Run `npm run build` and test the CLI before submitting changes.
